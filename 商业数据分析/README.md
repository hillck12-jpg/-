# CDA 一级认证商业数据分析：教材案例 Python 复现


## 项目简介
本项目以《CDA 一级认证教材：商业数据分析》配套案例为蓝本，将教材中以 Power BI 与 Excel 完成的全部业务图表迁移为 Python 实现，并将教材原有的 `.ipynb` 代码整理为规范的 `.py` 脚本。项目覆盖数据分析思维、分析方法、业务分析框架、用户画像与预测建模等核心章节，通过 Pandas 完成数据关联与指标计算，使用 Matplotlib / Seaborn / WordCloud 完成图表复现，形成一套可复用、可追溯的商业数据分析技术方案。

## 项目结构

项目按教材章节组织，每个章节内保持统一的三目录结构。整体架构如下：

```text
├── requirements.txt        # 依赖包清单
├── README.md               # 项目说明文档
│
├── 📁 第1章 数据分析思维/
│   ├── data/               # 原始 Excel 数据文件
│   ├── scripts/            # 核心代码脚本（含数据清洗与可视化绘图）
│   └── figures/            # 可视化输出图表（PNG 格式）
│
├── 📁 第2章 数据分析方法/
├── 📁 第3章 商业数据分析框架/
├── 📁 第5章 业务数据分析/
├── 📁 第9章 用户标签体系与用户画像专题/
├── 📁 第10章 使用效应分解方法做预报/
│
└── 📁 第7、8、11、12、13章/ 
    └── (教材该章无图表案例，目录留空)
```
- **`data/`**：存放原始 Excel / CSV 业务数据，保持教材原始字段不做改动
- **`scripts/`**：每个图表对应一个独立 `.py` 脚本，文件头注释说明对应的 PBIX 页面、数据来源与实现思路
- **`figures/`**：脚本运行后自动输出的 PNG 图表，文件名与脚本名一一对应

## 核心功能
1. **数据清洗与关联**：使用 Pandas 读取 Excel 多工作表数据，处理缺失值与日期格式，按主键完成事实表与维度表（商品、店铺、品类、员工）的关联，计算销售额、利润、折扣率、坪效等派生指标。
2. **图表复现**：涵盖趋势分析、对比分析、构成分析、分布分析、关系分析、桑基图六类分析方法，以及 KPI 卡片、漏斗图、同期群留存热力图、波士顿矩阵、RFM 帕累托图、词云、分解树、效应分解预测等典型业务图表。
3. **结果输出**：全项目共 30 余个脚本、70 余张图表，脚本基于 `Path(__file__)` 定位路径，可在任意目录运行，图表统一以高分辨率 PNG 自动保存至 `figures/`，可直接嵌入实验报告或 PPT。

## 环境配置
- **依赖包安装**：`pip install -r requirements.txt`
- **环境要求**：Python 3.8+，支持 Windows / macOS / Linux
- **主要依赖**：pandas、numpy、matplotlib、seaborn、wordcloud、openpyxl、statsmodels

## 快速使用
1. 教材原始数据已按章节放入各章 `data/` 目录下。
2. 在终端进入任意章节的 `scripts` 目录，运行对应脚本。
3. 运行后，图表将自动保存至该章 `figures/` 目录。

```bash
cd "第2章 数据分析方法/scripts"
python sankey_flow.py
python funnel_chart.py
```
