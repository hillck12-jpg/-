# 零售数据图表复现与分析

## 关于这个项目
这是一个基于 Python 的小实践。我把手里的一份 Excel 零售数据，通过代码进行了处理，并复现了一些常见的业务分析图表，目的是给自己留一套能直接拿来用的画图代码。

## 文件都在哪
- 📁 `data`：这里放我的原始 Excel 表格。
- 📁 `code`：里面是我写的 Python 脚本（包含数据处理和画图的代码）。
- 📁 `images`：代码跑出来的图表结果，都保存在这里。

## 我的运行环境
如果你也想跑一下我的代码，需要先安装这些库：
`pandas`, `matplotlib`, `openpyxl`（读取Excel用）
